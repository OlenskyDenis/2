# Інструкція швидкого старту та валідації (Quickstart)

## Огляд

Цей документ описує покроковий процес налаштування середовища, запуску збирача даних ОВДП Приват24 та валідації результатів у файлі Excel.

---

## 1. Системні вимоги та залежності

1. **Операційна система**: Windows 10/11 (підтримуються також Linux / macOS).
2. **Середовище виконання**: Python версії `3.10` або новішої (поточне середовище: Python `3.12.10`).
3. **Необхідні бібліотеки Python**:
   - `requests` — здійснення HTTPS-запитів до API Приват24.
   - `openpyxl` — робота з форматом `.xlsx` (таблиці, стилі, фільтри).
   - `pytest` (для запуску тестів).

### Встановлення залежностей:
```bash
pip install -r requirements.txt
```
*(або `pip install requests openpyxl pytest`)*

---

## 2. Сценарії запуску

### Сценарій А: Запуск у 1 клік на Windows (Для кінцевого користувача)

1. Відкрийте кореневу папку проекту у Провіднику Windows.
2. Зробіть подвійний клік на файлі [`run.bat`](file:///d:/2/run.bat).
3. Відкриється вікно консолі, відбудеться збір даних з Приват24, і консоль відобразить хід виконання:
   ```text
   Ініціалізація сесії Приват24...
   Завантаження котирувань ОВДП... Знайдено 40 випусків.
   Отримання залишків та графіків виплат...
   Збереження даних у bonds.xlsx...
   Готово! Дані збережено успішно.
   Для продовження натисніть будь-яку клавішу...
   ```
4. Відкрийте створений файл [`bonds.xlsx`](file:///d:/2/bonds.xlsx) у Microsoft Excel або вільному табличному процесорі.

---

### Сценарій Б: Запуск через командний рядок (CLI)

Запуск за замовчуванням (оновлює або створює `bonds.xlsx` у корені проекту):
```bash
python -m src.cli.main
```

Запуск зі збереженням у довільний файл:
```bash
python -m src.cli.main --output data/my_portfolio.xlsx
```

Запуск у режимі автоматизації (машинний вивід JSON у `stdout`):
```bash
python -m src.cli.main --json
```

## 3. Валідація результатів (Критерії успіху)

Після завершення роботи утиліти виконайте перевірку:

1. **Наявність файлу**:
   - Перевірте наявність файлу `bonds.xlsx` у вказаному каталозі.
2. **Аркуш `Актуальні котирування`**:
   - Містить 12 стовпців згідно з [контрактом структури Excel](file:///d:/2/specs/001-bond-yield-analyzer/contracts/excel_schema.md#аркуш-1-актуальні-котирування).
   - У стовпці `Кількість в наявності` присутні точні числові залишки (наприклад, `85217` або `0`).
   - Увімкнено автофільтр для всіх колонок.
3. **Аркуш `Історія котирувань`**:
   - Містить зріз на поточну дату `YYYY-MM-DD`.
   - Повторний запуск скрипта у той самий день не створює однакових дублікатів рядків.
4. **Аркуш `Графік виплат`**:
   - Містить перелік купонних виплат та повернення номіналу за кожним папером.
   - Минулі та майбутні виплати збережені у повному обсязі.

---

## 4. Перевірка обробки позаштатних ситуацій

### Тест 1: Файл Excel заблоковано користувачем
1. Відкрийте `bonds.xlsx` у додатку Microsoft Excel.
2. Запустіть `python -m src.cli.main`.
3. **Очікуваний результат**: Утиліта не падає з аварійним трейсбеком, виводить у `stderr` чітке повідомлення українською мовою з проханням закрити файл Excel, і завершує роботу з кодом помилки `1`. Тимчасовий файл видаляється, а попередній `bonds.xlsx` залишається непошкодженим.

### Тест 2: Відсутність файлу Excel при першому запуску
1. Видаліть або перемістіть `bonds.xlsx`.
2. Запустіть `python -m src.cli.main`.
3. **Очікуваний результат**: Утиліта автоматично створює новий робочий документ `bonds.xlsx` з усіма трьома аркушами, заголовками, стилями та автофільтрами.

---

## 5. Запуск автоматизованих тестів (TDD)

Для запуску повного набору тестів (юніт, контрактні та інтеграційні):
```bash
pytest
```

Для запуску окремих груп:
```bash
# Тільки модульні тести:
pytest tests/unit

# Контрактні тести API та структури Excel:
pytest tests/contract

# Інтеграційні тести CLI та файлової транзакційності:
pytest tests/integration
```
