## 1. Дослідження API Приват24 (Reverse-Engineering)

### 1.1. Ініціалізація гостьової сесії (Guest Session)
Для виконання публічних запитів до каталогу облігацій Приват24 не потрібна автентифікація користувача (логін/пароль/2FA). Використовується публічна гостьова сесія.

- **URL**: `POST https://next.privat24.ua/api/p24/init`
- **Заголовки**:
  ```http
  Content-Type: application/json
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36
  Origin: https://next.privat24.ua
  Referer: https://next.privat24.ua/bonds/list
  ```
- **Тіло запиту**: `{}`
- **Відповідь**:
  ```json
  {
    "status": "success",
    "data": {
      "xref": "5bbcfcf609b8967522a4625cceaa88dc",
      "base_url": "api/p24/pub/"
    }
  }
  ```
- **Кукі**: Сервер повертає сесійну куку `pubkey`, яку необхідно зберігати в `CookieJar` для наступних викликів.

### 1.2. Отримання загального каталогу котирувань (`bargaining`)
Один запит повертає повний реєстр усіх відкритих для торгів випусків облігацій (наразі 40 паперів).

- **URL**: `POST https://next.privat24.ua/{base_url}bonds`
- **Тіло запиту**:
  ```json
  {
    "action": "bargaining",
    "xref": "{xref}"
  }
  ```
- **Атрибути об'єкта облігації**:
  - `isin`: рядок (наприклад, `"UA4000238281"`)
  - `currency`: код валюти (`"UAH"`, `"USD"`, `"EUR"`)
  - `maturityDate`: дата погашення (формат `"YYYY-MM-DD"`)
  - `dayToMaturity`: кількість днів до погашення (число)
  - `isMilitary`: булевий прапорець військової облігації (`true`/`false`)
  - `priceBuy`: ціна купівлі з накопиченим купонним доходом (НКД) (число)
  - `yieldBuy`: заявлена дохідність купівлі (% річних) (число)
  - `sellPrice`: ціна зворотного викупу банком (число або `null`)
  - `yieldSell`: дохідність зворотного викупу (число або `null`)
  - `yieldType`: тип розрахунку дохідності (`"SIM"` / `"YTM"`)
  - `nearestCoupon`: дата найближчої купонної виплати

### 1.3. Отримання кількості в наявності та статусу продажу (`limits`)
Для отримання точного залишку паперів у банку («мін 1 макс 85217 шт.») надсилається запит із обов'язковим внутрішнім параметром `operation=s` (*sale* з позиції банку):

- **URL**: `GET https://next.privat24.ua/{base_url}bonds?action=limits&xref={xref}&isin={isin}&operation=s`
- **Відповідь**:
  ```json
  {
    "status": "success",
    "data": {
      "isin": "UA4000238281",
      "count": "80965",
      "minAmount": 500,
      "maxAmount": 99000000,
      "active": false
    }
  }
  ```
- **Ключові поля**:
  - `count`: залишок цінних паперів у продажу в банку (якщо випуск розкуплено — `"0"`);
  - `active`: прапорець активності торгів (чи дозволена купівля в поточний момент);
  - `minAmount`, `maxAmount`: мінімальний та максимальний ліміти суми угоди в гривні/валюті.

### 1.4. Отримання повного графіка виплат (`operations`)
Повертає вичерпний розклад усіх минулих і майбутніх купонів та погашення номіналу:

- **URL**: `POST https://next.privat24.ua/{base_url}bonds`
- **Тіло запиту**:
  ```json
  {
    "action": "operations",
    "xref": "{xref}",
    "isin": "{isin}"
  }
  ```
- **Відповідь**:
  ```json
  {
    "status": "success",
    "data": [
      {
        "dat": "2026-10-21",
        "kupon": 72.80,
        "payment": 0.0,
        "status": "waiting"
      },
      {
        "dat": "2027-04-21",
        "kupon": 72.80,
        "payment": 1000.0,
        "status": "waiting"
      }
    ]
  }
  ```
  - `dat`: дата виплати;
  - `kupon`: розмір купонного доходу на 1 папір;
  - `payment`: сума погашення номіналу (зазвичай 1000 грн/валюти на дату остаточного погашення).

## 2. Мережевий захист та безпека звернень (Anti-Ban & Stability)

1. **Мікро-троттлінг (Rate Limiting Prevention)**:
   - Обхід 40 випусків виконується послідовно із плаваючою затримкою (jitter) 50–100 мс між викликами.
   - 40 запитів залишку + графіків тривають сумарно ~3–4 секунди. Навантаження на сервер є мінімальним і не провокує блокування IP за HTTP 429.
2. **Сесійні помилки (Код 95 `session_was_expired`)**:
   - При отриманні статусу помилки сесії клієнт автоматично робить 1 виклик `init` та повторює невдалий запит.
3. **Мережеві таймаути та повтори (Retries)**:
   - Кожен HTTP-запит має таймаут 10 секунд.
   - При таймауті чи 502/503/504 робиться до 2 повторних спроб з експоненційною затримкою (0.5 с, 1.0 с).
4. **Транзакційність зрізу (All-or-Nothing)**:
   - Якщо під час циклу збору мережа падає невідновлювано, збір припиняється, а файл `bonds.xlsx` не змінюється.

## 3. Робота зі сховищем Excel (`openpyxl`)

### 3.1. Структура книги та аркушів
- Книга містить 3 аркуші: `Актуальні котирування`, `Історія котирувань`, `Графік виплат`.
- Створення з нуля: якщо `bonds.xlsx` відсутній, створюється новий `openpyxl.Workbook()`.
- Завантаження: якщо файл уже є, завантажується `openpyxl.load_workbook(filename)`.

### 3.2. Стилі, форматування та автофільтри
- Заголовки: напівжирний шрифт (`Font(bold=True)`), заливка світло-сірим/синім кольором (`PatternFill`), закріплення верхнього рядка (`freeze_panes = "A2"`).
- Числові формати:
  - Ціни: `#,##0.00`
  - Дохідності: `0.00%` або `0.00`
  - Залишок штук: `#,##0`
  - Дати: `YYYY-MM-DD`
  - Часові мітки: `YYYY-MM-DD HH:MM:SS`
- Автофільтри: `ws.auto_filter.ref = ws.dimensions` на всіх 3-х аркушах.

### 3.3. Атомарне збереження (Atomic Write)
- Запис спочатку здійснюється у тимчасовий файл `.bonds.xlsx.tmp`.
- Після успішного закриття файлу викликається `os.replace(".bonds.xlsx.tmp", "bonds.xlsx")`.
- Якщо файл заблоковано користувачем (`PermissionError`), система виводить у `stderr` вимогу закрити Excel і повертає код помилки 1, видаляючи `.tmp`.

## 4. Швидкий запуск на Windows (`run.bat`)

Для максимальної простоти запуску без ручного введення команд створюється `run.bat`:
```bat
@echo off
chcp 65001 > nul
echo ========================================================
echo   Оновлення бази даних облігацій Приват24 в Excel
echo ========================================================
python -m src.cli.main
if %ERRORLEVEL% NEQ 0 (
    echo.
    echo [ПОМИЛКА] Завершено з помилкою. Перегляньте повідомлення вище.
) else (
    echo.
    echo [УСПІХ] Базу bonds.xlsx успішно оновлено!
)
echo.
pause
```
