## 1. Доменні сутності (Entities)

### 1.1. Облігація (`Bond`)
Основна інформаційна одиниця цінного паперу в каталозі.

```python
from dataclasses import dataclass, field
from datetime import date, datetime
from typing import Optional, List

@dataclass
class Bond:
    isin: str                          # Унікальний міжнародний код (наприклад, "UA4000238281")
    name: str                          # Назва або найменування випуску
    currency: str                      # Код валюти: "UAH", "USD", "EUR"
    maturity_date: date                # Дата остаточного погашення
    days_to_maturity: int              # Залишковий термін у днях
    is_military: bool                  # Ознака військової облігації
    price_buy: float                   # Поточна ціна купівлі клієнтом (з НКД)
    yield_buy: float                   # Заявлена банком дохідність купівлі (% річних)
    sell_price: Optional[float] = None # Ціна зворотного викупу банком (або None)
    yield_sell: Optional[float] = None # Дохідність зворотного викупу (або None)
    yield_type: str = "SIM"            # Тип ставки банку: "SIM" або "YTM"
    stock_count: int = 0               # Залишок у продажу в банку (шт.)
    status: str = "Активний"           # "Активний", "Розкуплено або недоступно", "Знято з торгів / Погашено"
    min_amount: float = 0.0            # Мін. сума угоди
    max_amount: float = 0.0            # Макс. сума угоди
    updated_at: datetime = field(default_factory=datetime.now) # Час зняття зрізу
```

### 1.2. Історичний зріз котирування (`PriceSnapshot`)
Запис динаміки зміни вартості та залишку паперу на ринку.

```python
@dataclass
class PriceSnapshot:
    timestamp: datetime                # Дата і точний час фіксації (YYYY-MM-DD HH:MM:SS)
    isin: str                          # Код облігації
    currency: str                      # Валюта випуску
    price_buy: float                   # Ціна купівлі на момент зрізу
    yield_buy: float                   # Дохідність купівлі (%)
    sell_price: Optional[float]        # Ціна зворотного викупу
    yield_sell: Optional[float]        # Дохідність зворотного викупу
    stock_count: int                   # Кількість у наявності на момент зрізу (шт.)
    status: str                        # Стан торгів на момент зрізу
```

### 1.3. Подія грошового потоку (`CashFlowEvent`)
Елемент розкладу купонних виплат та погашення номіналу.

```python
@dataclass
class CashFlowEvent:
    isin: str                          # Код облігації
    currency: str                      # Валюта виплати
    payment_date: date                 # Календарна дата виплати
    event_type: str                    # "Купон" або "Погашення номіналу"
    amount: float                      # Грошова сума на 1 папір
    status: str = "Майбутня"           # "Майбутня" або "Здійснена"
```

## 2. Правила цілісності, дедуплікації та злиття (Integrity & Upsert Rules)

### 2.1. Аркуш «Актуальні котирування» (Зріз ринку)
- **Первинний ключ**: `isin`.
- **Логіка оновлення**:
  - Якщо ISIN уже є в аркуші, його рядок замінюється найсвіжішими даними нового зрізу.
  - Якщо новий ISIN з'явився на ринку — додається новий рядок.
  - Якщо раніше збережений ISIN зник із каталогу торгів — рядок **не видаляється**, а статус переводиться у `Знято з торгів / Погашено`.

### 2.2. Аркуш «Історія котирувань» (Часовий ряд)
- **Композитний ключ зрізу**: `(isin, date(timestamp))`.
- **Правило дедуплікації**:
  - Новий рядок дописується в кінець таблиці, якщо:
    1. Це перший запуск за поточну календарну добу;
    2. АБО якщо змінився хоча б один із ключових параметрів: `price_buy != last_price_buy` чи `stock_count != last_stock_count` чи `sell_price != last_sell_price`.
  - Якщо параметри ідентичні раніше збереженому запису за сьогодні — дублікат рядка не додається.

### 2.3. Аркуш «Графік виплат» (Неруйнівний календар)
- **Композитний ключ події**: `(isin, payment_date, event_type)`.
- **Неруйнівний upsert**:
  - Нові заплановані виплати додаються.
  - Наявні виплати за цим ключем актуалізуються (наприклад, статус або сума).
  - Записи, які зникли з сервера банку (наприклад, купони, дата яких минула), **ніколи не видаляються** з Excel, що гарантує збереження повної історії всіх виплат.
