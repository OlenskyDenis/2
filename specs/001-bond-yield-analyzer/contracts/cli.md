# Контракт інтерфейсу командного рядка (CLI) та файлу запуску

## Загальний опис

CLI інтерфейс призначений для автономного та автоматизованого запуску процесу збору котирувань ОВДП, перевірки залишків та формування локального реєстру Excel. Інструмент суворо дотримується принципів Конституції проекту: стандарти POSIX I/O потоків, розділення інформаційних та діагностичних повідомлень, зрозумілі коди завершення, а також підтримка швидкого запуску у Windows через пакетний файл `run.bat`.

---

## 1. Синопсис виклику

```bash
# Базовий запуск (створює або оновлює bonds.xlsx у поточному каталозі):
python -m src.cli.main

# Вказання альтернативного шляху до файлу Excel:
python -m src.cli.main path/to/my_bonds.xlsx
# або через опцію:
python -m src.cli.main --output path/to/my_bonds.xlsx

# Машиннозчитуваний режим (для конвеєрів та зовнішніх систем):
python -m src.cli.main --json

# Детальний діагностичний вивід:
python -m src.cli.main --verbose
```

---

## 2. Аргументи та опції

| Аргумент / Прапорець | Тип | За замовчуванням | Опис |
|---|---|---|---|
| `excel_path` | Positional (опціонально) | `bonds.xlsx` | Шлях до файлу Excel. Якщо не вказано, використовується `bonds.xlsx` у поточному каталозі. |
| `-o`, `--output` | Option (рядок) | `bonds.xlsx` | Альтернативний прапорець для вказання шляху до файлу Excel. |
| `--json` | Flag | `False` | Якщо встановлено, в `stdout` виводиться виключно валідний JSON-звіт про результати роботи, а текстові повідомлення пригнічуються. |
| `-v`, `--verbose` | Flag | `False` | Вивід детальних діагностичних повідомлень (трасування HTTP-запитів, розмір відповідей) у `stderr`. |
| `-h`, `--help` | Flag | - | Вивід структурованої довідки українською мовою та завершення з кодом `0`. |

---

## 3. Конвенція потоків введення/виведення (I/O Streams)

### Стандартний потік виведення (`stdout`)

У звичайному режимі (людинозчитуваний вивід українською мовою):
```text
Ініціалізація гостьової сесії Приват24... Успішно.
Завантаження котирувань ОВДП... Знайдено 40 випусків.
Отримання залишків та графіків виплат [====================] 100% (40/40)
Оновлення реєстру Excel (bonds.xlsx)...
  - Аркуш 'Актуальні котирування': 40 записів оновлено.
  - Аркуш 'Історія котирувань': 40 нових зрізів додано.
  - Аркуш 'Графік виплат': 186 виплат синхронізовано.
Збереження завершено успішно за 4.2 сек.
```

У режимі `--json`:
```json
{
  "status": "success",
  "file": "bonds.xlsx",
  "bonds_count": 40,
  "available_bonds_count": 12,
  "cashflows_count": 186,
  "duration_seconds": 4.21,
  "timestamp": "2026-09-24T12:00:00"
}
```

### Стандартний потік діагностики та помилок (`stderr`)

Усі діагностичні попередження, таймінги, трасування помилок та критичні збої направляються виключно у `stderr`:
- Заблокований файл Excel:
  ```text
  [ПОМИЛКА] Файл 'bonds.xlsx' заблоковано іншою програмою (ймовірно, відкрито в Microsoft Excel).
  Будь ласка, закрийте файл Excel та повторіть спробу.
  ```
- Мережевий збій:
  ```text
  [ПОМИЛКА] Не вдалося з'єднатися з сервером Приват24 після 3 спроб: HTTPSConnectionPool(host='next.privat24.ua', port=443): Max retries exceeded
  ```

---

## 4. Коди завершення (Exit Codes)

| Код | Значення | Умови виникнення |
|---|---|---|
| `0` | `SUCCESS` | Дані успішно завантажено, опрацьовано та збережено у файл Excel. |
| `1` | `RUNTIME_ERROR` | Помилка з'єднання з API, невалідна відповідь банку, помилка доступу до файлу (`PermissionError` через блокування процесом Excel). |
| `2` | `USAGE_ERROR` | Невідомі аргументи або невалідний синтаксис виклику CLI. |

---

## 5. Контракт файлу швидкого запуску (`run.bat`)

Для максимальної простоти запуску користувачем у середовищі Windows створюється пакетний файл `run.bat` у корені репозиторію.

### Вимоги до `run.bat`:
1. Кодування консолі: виклик `chcp 65001 > nul` на початку для коректного відображення українських літер.
2. Перевірка наявності Python:
   - Якщо `python --version` повертає помилку, вивести зрозуміле українське повідомлення: `"Помилка: Python не знайдено в системі. Встановіть Python 3.10+ та додайте його до PATH"` і виконати `pause`.
3. Запуск основного модуля: `python -m src.cli.main %*`.
4. Збереження результату виконання на екрані: обов'язковий виклик `pause` перед виходом, щоб вікно консолі не закривалося автоматично при подвійному кліку мишкою.
